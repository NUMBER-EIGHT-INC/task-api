## 登録

- メソッド / パス: POST /api/register
- ログイン: 不要
- 送るデータ(JSON):
    - name: 文字, 必須, 50文字まで
    - email: 文字, 必須, メールの形, すでに使われていないもの
    - password: 文字, 必須, 8文字以上
    - password_confirmation: パスワードの確認(同じ文字を入れる)
- 成功したら: 201 / ユーザーの情報とトークンを返す
- 失敗したら:
    - 422: 入力がまちがい

## ログイン

- メソッド / パス: POST /api/login
- ログイン: 不要
- 送るデータ(JSON):
    - email: 文字, 必須
    - password: 文字, 必須
- 成功したら: 200 / トークンを返す
- 失敗したら:
    - 422: メールまたはパスワードがまちがい
- メモ: どちらがまちがいか、わからないようにする

## ログアウト

- メソッド / パス: POST /api/logout
- ログイン: 必要
- 成功したら: 204 / 何も返さない
- 失敗したら:
    - 401: ログインしてない

## タスク一覧

- メソッド / パス: GET /api/tasks
- ログイン: 必要
- 成功したら: 200 / 自分のタスクの一覧を返す
- 失敗したら:
    - 401: ログインしてない
- メモ: 10件ずつ返す。?page=2 で次のページ

## タスク作成

- メソッド / パス: POST /api/tasks
- ログイン: 必要
- 送るデータ(JSON):
    - title: 文字, 必須, 100文字まで
    - description: 文字, 任意, 1000文字まで
    - is_done: true / false, 任意(なければ false)
- 成功したら: 201 / 作ったタスクを返す
- 失敗したら:
    - 401: ログインしてない
    - 422: 入力がまちがい

## タスク1件

- メソッド / パス: GET /api/tasks/{id}
- ログイン: 必要
- 成功したら: 200 / そのタスクを返す
- 失敗したら:
    - 401: ログインしてない
    - 403: 他の人のタスク
    - 404: そのタスクはない

## タスク更新

- メソッド / パス: PATCH /api/tasks/{id}
- ログイン: 必要
- 送るデータ(JSON): 直したいものだけ送る
    - title: 文字, 100文字まで
    - description: 文字, 1000文字まで
    - is_done: true / false
- 成功したら: 200 / 直したタスクを返す
- 失敗したら:
    - 401: ログインしてない
    - 403: 他の人のタスク
    - 404: そのタスクはない
    - 422: 入力がまちがい

## タスク削除

- メソッド / パス: DELETE /api/tasks/{id}
- ログイン: 必要
- 成功したら: 204 / 何も返さない
- 失敗したら:
    - 401: ログインしてない
    - 403: 他の人のタスク
    - 404: そのタスクはない

## 自分の情報

- メソッド / パス: GET /api/me
- ログイン: 必要
- 成功したら: 200 / ログイン中のユーザーを返す
- 失敗したら:
    - 401: ログインしてない
